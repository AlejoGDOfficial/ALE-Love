# ALE Love

ALE Love is a small framework *highly* inspired by [**HaxeFlixel**](https://github.com/HaxeFlixel/flixel) to improve and simplify the user experience in [LÖVE 2D](https://love2d.org/)

---

Some external projects are used, such as the following (included in `ale.std`):
- [Class in Lua](https://github.com/SadNguyen2107/Class-In-Lua)
